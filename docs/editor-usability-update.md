# 编辑器日常操作完善

范围：沿用 Vue、Monaco 和现有事件桥接，仅完善前端编辑体验；不增加依赖或后端接口。

| 能力 | 现状与处理 |
| --- | --- |
| 撤销、重做、查找替换、括号配对 | 已有，补充菜单快捷键提示 |
| 行注释、缩进、移动和复制行、删除行 | 接入 Monaco 原生命令，增加菜单入口 |
| 多选、扩大和缩小选区 | 接入 Monaco 原生命令 |
| 跳转行列、括号跳转、折叠展开、命令面板 | 增加菜单入口，使用 Monaco 现有快捷键 |
| 原生命令面板和菜单语言 | 加载 Monaco 随包中文资源 |
| 自动换行、空白字符 | 增加视图开关，随现有工作台快照保存 |
| 标签切换 | 保存与恢复光标、选区、滚动和折叠状态；文本与二进制视图切换保留文本编辑器 |
| 关闭标签 | 清理模型、位置快照和诊断计时器，重新打开读取当前内容 |
| 格式化、语义重命名、跨文件索引 | 留待语言服务实现，不添加不可用入口 |

实施顺序：

1. 扩展现有编辑器动作桥和菜单，接入常用命令及快捷键提示。
2. 在现有面板 store 中加入两个显示开关，复用快照保存；Alt+Z 走相同状态。
3. 收敛 Monaco 模型与视图状态管理，修复标签切换和关闭模型的生命周期。
4. 用真实 Monaco 文本模型验证模型复用、关闭重开与撤销历史；运行现有测试、类型检查及构建。

视图状态只保存在本次会话内，不增加磁盘级光标快照。UI 验证最多截图，不执行浏览器自动交互。
