# truth 纵向结构时间线

用户已确认：纵向事件时间线，每个 entry 之间加分隔线；第一版包含循环嵌套与折叠、interrupt 入口、跳转定位和局部时间标记。

## 方案与边界

采用扩展现有 Rust 结构分析的方案。仅修改前端无法得到循环范围和 interrupt 入口；引入运行模拟器则超出本次阅读源码的用途。继续使用现有 truth，不增加依赖或维护 truth 分支。

现有 `ScriptAnalysis` 增加 `timeline`，保留已有符号、引用及扁平事件字段。Rust 输出按源码顺序排列的 entry 和递归结构节点；前端仅负责呈现、折叠和定位，不解析脚本语法。节点保留源码行范围、源码摘要和可定位的跳转目标。

## 呈现

- entry 标题可折叠，标题显示名称；相邻 entry 用完整分隔线分开。
- 组内采用细竖线、时间节点和紧凑指令行，同一时间标记下的指令成组。
- 时间标记保留原始绝对值或 `+N` 相对值；循环中的标记属于该源码结构，不推演多轮运行时间。
- `loop`、`while`、`do`、`times` 作为带回折提示的可折叠结构，条件或次数保留源码写法。
- `interrupt[n]:` 保留在源码位置；连续多个入口标签合并展示。不假定 interrupt 是带有隐式返回的独立函数，也不把后续时间重置为零。
- 显示标签、goto、break、continue、return；已知目标可点击定位，目标未知仍可定位当前语句。
- 当前光标对应的事件高亮。长名称与源码摘要单行省略、悬停查看完整内容。
- 使用现有 VS Code 风格深色配色，保留窄侧栏可读性，不加入宽轨道、拖动修改时间、运行模拟或播放控制。

## 验证

Rust 用实际源码覆盖嵌套循环、局部时间、共用 interrupt 入口和跳转定位。序列化字段在 wire-format 测试固定。前端只为折叠、定位、光标高亮添加行为测试；样式通过不同宽度静态截图检查，不执行浏览器自动点击流程。
