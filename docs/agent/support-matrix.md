## 范围外

`mission.msg`／`titlemsg.txt`、TH06–09 的旧 END 格式、TH06NC、Alcostg 均不在这 53 项中。编译器内部存在其他入口，不代表 Studio 或本手册已经承诺支持。TH095／TH125 没有普通关卡 MSG profile；TH103 是 STD 的实际 profile，不给它虚构 MSG／END。

本轮八份示例编译的目标限定在 manifest 所列版本，不把一个例子的成功自动推广为全部 53 项的编译验收。来源、固定修订及历史差异见 [sources.md](sources.md)。
